## Summary

- Rule available since: `v0.0.1`
- Category: `lint/style/usePackageComment`
- This rule is **recommended**, meaning it is enabled by default.
- This rule doesn't have a fix.
- The default severity of this rule is **warning**.

## Configuration
```yaml title="vint.yaml"
settings:
  lint/style/usePackageComment:
    # rule options here
```

## Details

Incorrect or missing package comment.

Packages should have a package comment that begins with "Package [name] ..." to describe the package's purpose. This is important for documentation generated by `godoc`.

Source: https://staticcheck.dev/docs/checks/#ST1000

## Examples

### Invalid

```golang
// This package does stuff
package mypackage
```

### Valid

```golang
// Package mypackage provides utilities for processing data.
package mypackage
```
