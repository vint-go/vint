## Summary

- Rule available since: `v0.0.1`
- Category: `lint/style/useStandardCodegenComment`
- This rule is **recommended**, meaning it is enabled by default.
- This rule doesn't have a fix.
- The default severity of this rule is **warning**.

## Configuration
```yaml title="vint.yaml"
settings:
  lint/style/useStandardCodegenComment:
    # no additional options
```

## Details

Detects malformed 'code generated' file comments. Go has a standard format for marking files as code-generated: `// Code generated .* DO NOT EDIT.` This checker flags comments that indicate the file is auto-generated but do not conform to the standard format.

Source: https://github.com/go-critic/go-critic

## Examples

### Invalid

```golang
// this file was automatically generated, do not edit
package mypackage
```

```golang
// generated code - do not edit
package mypackage
```

### Valid

```golang
// Code generated by mytools; DO NOT EDIT.
package mypackage
```
